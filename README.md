# 🚢 HERO 2.0 Workshop
## 통합 출석 체크 & 실시간 운영 관리 시스템

> **대규모 사내 워크숍 운영 과정에서 발생하는 참가자 조회, 출석 확인, 반·조 안내 및 운영 현황 관리 업무를 하나의 웹 시스템으로 통합한 개인 포트폴리오 프로젝트입니다.**

> **※ 본 저장소는 Hanwha Ocean에서의 업무 경험을 바탕으로 재구성한 개인 포트폴리오용 데모이며, 회사의 공식 공개 서비스 또는 공식 오픈소스 프로젝트가 아닙니다.**

---

## 💡 프로젝트 배경

대규모 워크숍 운영 과정에서는 참가자가 현장에서 명단을 직접 확인하여 자신의 **반·조 정보를 찾고**, 출석은 별도의 절차를 통해 처리해야 합니다.

운영진 역시 참가자 명단, 출석 여부, 현장 안내 정보를 여러 화면과 파일에서 관리해야 하기 때문에 차수가 반복될수록 확인 및 후처리 업무가 증가합니다.

이를 개선하기 위해 다음 과정을 하나의 웹 시스템으로 통합했습니다.

**참가자 조회 → 본인 확인 → 출석 인증 → 반·조 확인 → 관리자 실시간 현황 관리**

---

## 🎯 해결하고자 한 문제

### 참여자 관점
- 많은 인원 중 자신의 정보를 직접 찾아야 하는 불편
- 출석 확인과 반·조 안내 절차의 분리
- 자신의 출석 여부를 즉시 확인하기 어려운 문제
- 사전 명단 누락 시 운영진에게 별도로 문의해야 하는 문제

### 운영진 관점
- 참가자 명단과 출석 현황을 반복적으로 확인해야 하는 운영 공수
- 장소·차수·반·조별 현황을 즉시 파악하기 어려움
- 수동 출석 처리 및 출석 취소 관리의 번거로움
- 매 차수 반복되는 명단 업로드 및 결과 데이터 정리

---

## 💡 Solution

참여자와 운영진의 사용 목적을 구분하여 시스템을 세 개의 화면으로 구성했습니다.

```text
┌─────────────────────────────────────────────────────────────────────┐
│                     HERO 2.0 WORKSHOP SYSTEM                       │
├─────────────────────┬─────────────────────┬─────────────────────────┤
│   참여자 모바일 웹   │    현장 QR 배너     │    관리자 대시보드      │
├─────────────────────┼─────────────────────┼─────────────────────────┤
│ • 사번 조회         │ • 현장 QR 표시      │ • 실시간 출석률 확인    │
│ • 출석코드 인증     │ • 장소별 안내       │ • 참가자 검색/필터      │
│ • 반·조 정보 확인   │ • 출석코드 표시     │ • 수동 출석/취소        │
│ • 현장 즉시 등록    │ • 실시간 시계       │ • CSV 업로드/내보내기   │
└─────────────────────┴─────────────────────┴─────────────────────────┘
```

## 🌟 주요 기능

### 1. 참여자 모바일 웹

#### 🔎 사번 기반 참가자 조회
참여자가 사번을 입력하면 사전 등록된 명단과 비교하여 본인의 워크숍 정보를 조회합니다.

조회 후 다음 정보를 확인할 수 있습니다.

- 이름
- 워크숍 일자
- 장소
- 차수
- 반
- 조
- 현재 출석 여부

#### 🔐 2단계 출석 인증

단순 사번 입력만으로 출석 처리되지 않도록 구성했습니다.

```text
사번 입력
   ↓
참가자 확인
   ↓
임시 인증 세션 발급
   ↓
현장 출석코드 입력
   ↓
출석 완료
```

운영진이 현장에서 안내한 유효한 출석코드를 입력해야 최종 출석으로 인정됩니다.

#### 🪑 반·조 정보 즉시 확인
출석 과정에서 자신의 반과 조 정보를 바로 확인할 수 있도록 구성했습니다.

#### 📝 현장 즉시 등록
사전 명단에 등록되지 않은 참여자는 현장에서 필요한 정보를 입력하여 등록 후 출석을 진행할 수 있습니다.

#### 🎉 인터랙티브 피드백
출석 성공 시 애니메이션과 함께 출석 완료 여부 및 배정 정보를 즉시 제공합니다.

---

### 2. 현장 QR 배너

워크숍 현장의 대형 모니터 또는 빔프로젝터에 띄워 사용할 수 있는 화면입니다.

#### 주요 기능
- 모바일 출석 페이지 QR 코드 표시
- 거제 / 서울 / 부산 장소별 화면 전환
- 해당 장소의 활성 출석코드 표시
- 실시간 시계
- 대형 디스플레이에 최적화된 화면 구성

참여자는 별도의 URL을 입력하지 않고 현장 QR을 스캔하여 출석 페이지에 접속할 수 있습니다.

---

### 3. 관리자 통합 대시보드

운영진이 전체 워크숍의 출석 현황과 참가자를 한 화면에서 관리할 수 있도록 구성했습니다.

#### 📊 실시간 출석 현황
- 전체 참여자 수
- 출석 완료 인원
- 미출석 인원
- 출석률
- 장소별 출석 현황

#### 🔎 다차원 검색 및 필터
- 일자
- 장소
- 차수
- 반
- 조
- 출석 여부
- 사번
- 이름

#### ✏️ 참가자 관리
- 신규 참가자 등록
- 참가자 정보 수정
- 개별 삭제
- 전체 명단 초기화
- 수동 출석 처리
- 출석 취소

#### 🕐 출석 시도 이력
참여자가 언제 어떤 방식으로 출석을 시도했는지 기록하여 운영진이 이력을 확인할 수 있도록 구성했습니다.

#### 🔑 출석코드 관리
- 일자별 코드 생성
- 장소별 코드 설정
- 활성 / 비활성 관리
- 출석 가능 시간 설정

#### 📂 대량 명단 CSV 업로드
참가자 명단을 한 명씩 입력하지 않고 CSV 파일을 통해 일괄 등록할 수 있습니다.

지원 데이터 예시:

```text
장소
차수
일자
사번
이름
반
조
```

기존 명단에 추가하거나 새로운 명단으로 교체하는 방식으로 운영할 수 있습니다.

#### 📤 결과 데이터 내보내기
현재 조회 중인 참가자 목록과 출석 결과를 CSV 형식으로 내려받아 후속 업무에 활용할 수 있습니다.

## 🔄 업무 프로세스 변화

### 기존 방식

```text
참가자 명단 확인
      ↓
본인 정보 직접 검색
      ↓
별도 출석 절차
      ↓
운영진 수기 확인
      ↓
출석 결과 정리
```

### 개선 방식

```text
QR 접속
   ↓
사번 입력
   ↓
출석 인증
   ↓
반·조 확인
   ↓
관리자 화면 실시간 반영
```

참여자에게는 **정보 탐색 단계를 줄이고**, 운영진에게는 **반복적인 확인·정리 업무를 하나의 시스템으로 통합**하는 것을 목표로 설계했습니다.

## 🙋‍♀️ 프로젝트에서 집중한 부분

### 1. 현장 문제 정의
단순히 웹페이지를 만드는 것이 아니라 현장에서 반복적으로 발생하는

- 명단 검색
- 출석 확인
- 반·조 안내
- 현황 파악
- 결과 정리

업무를 하나의 프로세스로 연결하는 데 중점을 두었습니다.

### 2. 사용자별 화면 분리
동일한 시스템을 사용하지만 목적이 다른 사용자를 구분했습니다.

- **참여자** → 빠르고 직관적인 출석 및 배정 정보 확인
- **현장 운영진** → QR 및 출석 정보 안내
- **관리자** → 전체 출석 현황 및 참가자 관리

### 3. 운영 예외 상황 반영
실제 현장에서 발생할 수 있는 상황을 고려하여 다음 기능을 설계했습니다.

- 사전 명단 누락
- 중복 출석 시도
- 출석 취소
- 운영진 수동 출석
- 장소별 출석코드 변경
- 명단 대량 변경

### 4. 생성형 AI를 활용한 업무 개선
Google AI Studio를 활용해 요구사항을 구조화하고 빠르게 프로토타입을 구현한 뒤, 실제 운영 흐름을 기준으로 기능을 반복적으로 수정·보완했습니다.

**업무 문제 정의 → 요구사항 구조화 → 기능 설계 → 구현 → 테스트 → 개선**

의 흐름으로 프로젝트를 진행했습니다.

## 📡 REST API 명세

### 참여자 API (`/api/attendance`)

- `GET /api/attendance/info`  
  서버 시간 및 기본 운영 정보 조회

- `POST /api/attendance/verify-employee`  
  사번 유효성 검증 및 인증 세션 발급

- `POST /api/attendance/check-in`  
  출석코드 검증 및 출석 처리

- `POST /api/attendance/self-register`  
  사전 명단 미등록 참가자 현장 등록

### 관리자 API (`/api/admin`)

- `POST /api/admin/login`  
  관리자 로그인 및 인증 토큰 발급

- `GET /api/admin/overview`  
  출석 통계 요약 조회

- `GET /api/admin/participants`  
  참가자 목록 검색 및 다차원 필터링

- `POST /api/admin/participants`  
  신규 참가자 단건 등록

- `PUT /api/admin/participants/:id`  
  참가자 정보 수정

- `DELETE /api/admin/participants/:id`  
  참가자 삭제

- `POST /api/admin/participants/clear-all`  
  전체 참가자 명단 초기화

- `POST /api/admin/participants/bulk-upload`  
  CSV 기반 참가자 명단 일괄 등록

- `POST /api/admin/attendance/manual-checkin`  
  관리자 수동 출석 처리

- `POST /api/admin/attendance/cancel`  
  출석 기록 취소

- `POST /api/admin/clear-all-attendance`  
  전체 출석 기록 초기화

- `GET /api/admin/attendance-codes`  
  출석코드 목록 조회

- `POST /api/admin/attendance-codes`  
  신규 출석코드 등록

- `PUT /api/admin/attendance-codes/:id`  
  출석코드 수정

- `DELETE /api/admin/attendance-codes/:id`  
  출석코드 삭제

- `POST /api/admin/attendance-codes/clear-all`  
  전체 출석코드 삭제

- `POST /api/admin/attendance-codes/generate-defaults`  
  데모용 기본 출석코드 생성

- `POST /api/admin/reset-demo`  
  데모 데이터 초기화
